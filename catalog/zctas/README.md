American Community Survey 2020–2024 5-year indicators for all 33,791 ZIP Code Tabulation Areas. A ZCTA [is not a ZIP code](https://www.census.gov/programs-surveys/geography/guidance/geo-areas/zctas.html) — it is the Census Bureau's block-built approximation of a USPS 5-digit delivery area — and it nests in nothing, so `state` is NULL on every row and there is no prefix join to counties or tracts. Six collections share these rows: [income](https://source.coop/portolan-mirrors/us-census-catalog/zctas/zcta-income/collection.json), [people](https://source.coop/portolan-mirrors/us-census-catalog/zctas/zcta-people/collection.json), [housing](https://source.coop/portolan-mirrors/us-census-catalog/zctas/zcta-housing/collection.json), [connectivity](https://source.coop/portolan-mirrors/us-census-catalog/zctas/zcta-connectivity/collection.json), [wellbeing](https://source.coop/portolan-mirrors/us-census-catalog/zctas/zcta-wellbeing/collection.json) and the wide 135-column [all indicators](https://source.coop/portolan-mirrors/us-census-catalog/zctas/zctas/collection.json) table, whose GeoParquet and PMTiles stay at `zctas/zctas.parquet` and `zctas/zctas.pmtiles`. All six hold the same `geoid` and the same geometry and join 1:1. The medians thin out at this geography — `median_gross_rent` is NULL on 23.79% of ZCTAs and `median_hh_income` on 9.60% (measured) — so read each collection's `*_cv` columns and its AGENTS.md before mapping. [data.census.gov](https://data.census.gov/) is authoritative.
