About this atlas

No API. No server.
Just files.

The Census Atlas is a demonstration of cloud-native geospatial. Every map you pan, every number in every popup and every byte behind them comes from static files on object storage, read directly by your browser over HTTPS.

There is no tile server, no feature service, no database and no API in front of the data. The map reads PMTiles, a single-file tile archive. The tables are GeoParquet. The metadata is STAC. This page is static too. Nothing here can rate-limit you, go down on its own, or charge for a query.

That is the point: the data is not trapped behind an interface. It is yours to download, query and join — with DuckDB, with Python, or by pointing an LLM at it.
