# Census Atlas — explorer app

A zero-build web viewer for the published catalog at
`https://data.source.coop/portolan-mirrors/us-census-catalog`. Plain ES
modules; MapLibre GL + PMTiles from CDN pins; no framework, no bundler,
no server. deck.gl is deliberately not used — every layer is a 2D vector
choropleth that MapLibre renders natively, and deck.gl would force a
bundler for no visual gain (see `docs/superpowers/specs/`).

## What it does

- Browses all 53 collections through `manifest.json`, grouped by geography,
  with the catalog's own rendered thumbnails.
- Renders the catalog's published MapLibre style JSONs verbatim and builds
  each legend from the style's paint expression plus its
  `portolan:column` / `portolan:breaks` metadata.
- Trends collections get a time dock: twelve indicators, a diverging
  change view, 2015-2019 / 2020-2024 level views with a cross-fade,
  a ▶ animation, and a synced side-by-side swipe comparison. The tiles
  carry the 2020-2024 row with the `chg_*` columns, so the 2015-2019
  value is computed in the paint expression as value minus change.
- Search covers places and datasets: states and counties from the baked
  `gazetteer.json`, all 32,612 places by range-reading the published
  `places.parquet` in the browser with hyparquet, and collections/styles
  by title, description and column name.
- Every collection panel links the GeoParquet, PMTiles, STAC document,
  README and upstream census.gov source files, with copyable DuckDB and
  GeoPandas snippets. Hive-partitioned collections get the anonymous-S3
  DuckDB form, because the HTTPS gateway has no listing for globs.
- The URL hash carries collection, view, period and camera, so any view
  is shareable.

## Development

```bash
cd apps/explorer
python3 serve.py 8899        # python -m http.server breaks PMTiles (no Range)
node --test *.test.mjs       # pure-module tests: styles, format, hash, snippets
```

`?base=<url>` points the app at another catalog root, e.g. a local tree
served with Range support.

After any change to catalog metadata or styles, regenerate the manifest
and gazetteer:

```bash
python3 tools/make_viewer_manifest.py
```

## Deployment

`.github/workflows/pages.yml` deploys this directory to GitHub Pages on
pushes that touch `apps/**`. Enable Pages (Settings → Pages → GitHub
Actions) once per repository. Only tracked files ship; `serve.py` and the
test files are removed from the site.

## Files

| file | role |
| --- | --- |
| `index.html`, `style.css` | shell and the "statistical atlas" look |
| `app.js` | map, state, sidebar, legend, time dock, swipe, popups |
| `styles.js` | style resolution, legend extraction, trends layers (pure) |
| `search.js` | place/dataset combobox, hyparquet places loader |
| `format.js`, `hash.js`, `snippets.js` | formatting, URL state, query snippets (pure) |
| `manifest.json`, `gazetteer.json` | generated by `tools/make_viewer_manifest.py` |
